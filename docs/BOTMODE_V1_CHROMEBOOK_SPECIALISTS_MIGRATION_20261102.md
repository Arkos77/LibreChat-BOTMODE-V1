## Autres éléments vérifiés — pas de complexité nouvelle sans nécessité

1. **Modèle gratuit** : le fournisseur OpenRouter documente `nvidia/nemotron-3.5-super-vl:free` à prix **0** et accepte `tools`/`tool_choice` : https://openrouter.ai/nvidia/nemotron-3.5-super-vl%3Afree . Cela ne démontre pas, à lui seul, une mission native hébergée de bout en bout sur ce Chromebook. Ne pas basculer vers la variante **payante** sans mandat. Le fournisseur gratuit signale des réserves de confidentialité pour les données personnelles : ne pas l'utiliser pour les documents sensibles sans décision informée.
2. **Documents/RAG — fonction non qualifiée et backend absent dans Lite.** `docker-compose.botmode-lite.yml` désactive volontairement le service `rag_api` (profil full) et force `RAG_API_URL=`. Le conteneur 3081 ne possède pas de RAG accessible dans sa pile actuelle. La documentation officielle https://www.librechat.ai/docs/configuration/rag_api confirme que le file search RAG nécessite RAG API et une base vectorielle. Le rôle DOCUMENTS conserve l'outil **autorisé** `file_search`, mais **son exécution n'est pas qualifiée et un upload de recherche RAG échouerait sans backend**. Ne pas démarrer le profil Full sur Chromebook (peu de RAM et zéro swap) ; si nécessaire, fournir ultérieurement un backend RAG hébergé/léger explicitement autorisé.
3. **Code — outil autorisé, exécution non qualifiée.** `CODE.tools=['execute_code']` est bien persisté, mais dans le conteneur test, `LIBRECHAT_CODE_BASEURL` et `LIBRECHAT_CODE_API_KEY` sont absents, et aucun service Code Interpreter distinct ne tourne. LibreChat https://www.librechat.ai/docs/configuration/tools/code_interpreter impose une API d'exécution de code et son authentification. Ne pas confondre la présence d'un outil dans MongoDB avec un environnement d'exécution fonctionnel ; pas de nouveau conteneur local sous contrainte RAM.
4. **Recherche web — outil autorisé, fournisseur à confirmer.** `RECHERCHE.tools=['web_search']` est sauvegardé. Les variables globales usuelles Serper, Tavily, SearXNG et Search Provider sont absentes de l'environnement API ; une configuration ou des clés **par utilisateur** peuvent exister et n'ont pas été exposées ni modifiées. Une recherche web réelle avec ce compte n'a pas été exécutée dans ce lot.
5. **Sécurité et version** : les 15/17 avis historiques disposent de correctifs ciblés sur la candidate ; les deux LOW `deepmerge` et `elliptic` sont acceptés **uniquement temporairement jusqu'au 16/11/2026**, issue #109. `main` et la release stable `v1.0.1` sont inchangés.
