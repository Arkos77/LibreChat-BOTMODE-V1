- Nouveau test sans dépendance externe : `python3 -B -m unittest discover -s scripts/botmode/tests -p test_lite_free_config.py`, PASS. Il impose : **pas de hostModelRouting**, endpoint OpenRouter sans modèle payant ni `openrouter/free` dynamique, modèle primaire gratuit explicite, et capacité native `subagents` toujours présente.

Les alertes de `main` et la release stable `v1.0.1` restent inchangées. Les anciennes images Docker, volumes et sauvegardes de rollback ne sont pas supprimés (disque 91 % utilisé).
