# Research v2 implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Separate verified research provenance from deterministic public source presentation.
**Architecture:** Keep research-v1 unchanged. Admit new BOTMODE plans with research-v2, retain the existing observation topology and durable Oracle state, and render a public result only after all planned verdicts are revalidated.
**Tech Stack:** TypeScript, native agents SDK, Jest, existing JS host wrappers.
**Spec:** docs/superpowers/specs/2026-10-25-research-citation-contract-design.md, approved by owner on 25 October 2026.

## Global Constraints

- Offline work only; no push, Docker, external inference, installation or stable promotion.
- Preserve raw candidates, v1 behavior, task identity, evidence, review and failure criteria.
- No URL insertion into Oracle candidates, no forced success, no retry loop.
- Existing researchExecutionVersion=1 describes the unchanged two-phase topology; the persisted outputContract selects citation semantics.

## Review Focus

- Rejected historic v1 candidates must not be reinterpreted as v2.
- Render only current task-bound observations and exact, revalidated durable candidates.
- Preserve honest failure and independent evidence requirements.
- Normal completion and warm/cold resumed publication must use the same rendered content.
- Paused/interrupted graphs must not publish a partial source list or reuse an earlier render.
